"""Pixel measurements for one probed still (fudai-wall pixel gate).

Usage: pixel_measure.py <still.png>
Prints one JSON object:
  flat_pct / detail_pct  - RULES S5 block measure: 32x32 blocks on grayscale;
                           flat block = std < 5, detail block = std >= 12.
  discs                  - rendered head discs found by skin segmentation:
                           a skin component ringed by the characters' dark
                           outline. Each disc: skin bbox, expanded bbox
                           (outline + hair/hat allowance, +12% per side),
                           area, dark-adjacency ratio.
Calibration (2026-11-23, chunk2d stills): F537 mocker silhouette 648x624 px
vs the staging audit's 480 px model disc (1.32x, hat-inclusive); F687 mayor
disc centre (553,30) r~473 vs projected (540,653) r448 - the gate therefore
MEASURES discs in the image instead of trusting projected centres.
"""
import json, sys
import numpy as np
from PIL import Image
from scipy import ndimage

def components(mask):
    lab, n = ndimage.label(mask)
    return lab, n

def main():
    path = sys.argv[1]
    img = Image.open(path).convert('RGB')
    a = np.asarray(img).astype(np.int32)
    H, W = a.shape[:2]
    R, G, B = a[:, :, 0], a[:, :, 1], a[:, :, 2]

    # ---- S5 block measure (grayscale, 32x32 blocks) ----
    gray = (0.299 * R + 0.587 * G + 0.114 * B)
    bs = 32
    nb = 0; flat = 0; detail = 0
    for y in range(0, H - bs + 1, bs):
        for x in range(0, W - bs + 1, bs):
            s = gray[y:y + bs, x:x + bs].std()
            nb += 1
            if s < 5: flat += 1
            if s >= 12: detail += 1
    flat_pct = round(100.0 * flat / nb, 1)
    detail_pct = round(100.0 * detail / nb, 1)

    # ---- head discs: skin mask + dark-outline adjacency ----
    skin = (R > 130) & (R - B > 25) & (R - G > 8) & (R - G < 95) & (G - B > 5) & (G - B < 80)
    dark = (R < 85) & (G < 75) & (B < 75)
    lab, n = components(skin)
    discs = []
    if n:
        for root in range(1, n + 1):
            m = lab == root
            area = int(m.sum())
            if area < 6000:
                continue
            ys, xs = np.nonzero(m)
            x0, x1, y0, y1 = int(xs.min()), int(xs.max()), int(ys.min()), int(ys.max())
            # dark adjacency: dilate by 3 px, ring = dilated & ~m
            d = ndimage.binary_dilation(m, iterations=3)
            ring = d & ~m
            ring_n = int(ring.sum())
            adj = float((ring & dark).sum()) / ring_n if ring_n else 0.0
            bw, bh = x1 - x0 + 1, y1 - y0 + 1
            aspect = bw / max(bh, 1)
            if adj < 0.30 or not (0.55 <= aspect <= 2.3):
                continue
            ex = round(bw * 0.12); ey = round(bh * 0.12)
            discs.append({
                'skin': [x0, y0, x1, y1],
                'disc': [max(0, x0 - ex), max(0, y0 - ey), min(W - 1, x1 + ex), min(H - 1, y1 + ey)],
                'centre': [round((x0 + x1) / 2), round((y0 + y1) / 2)],
                'area': area, 'adj': round(adj, 2),
            })
    discs.sort(key=lambda d: -d['area'])
    print(json.dumps({'file': path, 'size': [W, H], 'flat_pct': flat_pct,
                      'detail_pct': detail_pct, 'discs': discs}))

if __name__ == '__main__':
    main()

# Production and rules — the operating law of the heart

This folder is the complete Creatorize Suite **0.28.3**, fully extracted (see `COMPLETENESS.md` and
`EXTRACTION.md`). The heart — the main-process core — is at
`suite-win-portable/app.asar.extracted/out/main/index.js`, with its Python pipeline spine at
`suite-win-portable/app.asar.extracted/pipeline-scripts/`. The rules below are distilled **only**
from the extracted files themselves; each rule names its source. Nothing here is imported from
outside the heart.

The flagship method is the cartoon-shorts skill
(`suite-win-portable/resources/templates/skill/cartoon-shorts/SKILL.md`); the other 18 skills carry

## 1. The five passes — order is law

Every film is built in five passes, in this order, each run from its own step file, each standing
alone and keeping what the others made. "End to end" = the five in that order, with the director's
whole-film review between them. *(SKILL, "The stages")*

| # | Pass | Step file | Exit (summary; the full list is in the step file) |
|---|---|---|---|
| 1 | Build | `steps/build.md` | Frame 0 an expressive face; every word in a line; PROP GUARD passes; critic YES |
| 2 | Camera angles | `steps/camera.md` | Every fast move clean on a full-rate strip; `film_check same` passes; critic YES |
| 3 | Environment overhaul | `steps/environment.md` | The set bar passes; depth behind every face; critic YES |
| 4 | Add post processing | `steps/post.md` | Numbers per place class; faces the sharpest thing; set bar still passes; critic YES |
| 5 | Shading pass | `steps/shading.md` | `shade_jumps`/`calm` looked at; set bar still passes; critic YES |

Priority inside the work, the owner's words: **characters first** ("they are what makes the whole
thing feel alive"), **then the camera, the set, the post, the light**. *(SKILL, "Your role")*

## 2. How every pass runs — the loop

1. **Read** the step file, its named references, every earlier pass's `lessons/*.md` HANDOVER, the
   bar stills, and the guide pages for this pass (always pages 01 and 10).
2. **Before touching anything:** `render_frames` at `scale: 1` on 4–6 key times + a whole-film
   `film_sheet`. Write the gap list — what the bar has that these frames lack, worst first.
3. **Work:** change something real, `check_preview`, LOOK (`film_sheet`, `strip` on fast moves,
   `render_frames` on faces). Fix the worst thing radically, at its cause. Again.
4. **Machine checks** of the pass: every FAIL fixed at its cause. *Numbers point, eyes decide.*
5. **Critic rounds** (see §3). 6. **Handover:** `lessons/<step>.md`, ending with the HANDOVER block.
*(SKILL, "How every pass runs")*

## 3. Critic discipline — you never grade your own work

- Every pass ends with critic rounds: a **new** agent that never saw your reasoning sees your
  frames **blind-mixed with bar frames** (same size, shuffled, neutral names; the key file is
  never shown to the critic) and answers in a fixed form.
- Read the answer; count the blind score (bar pictures it took for yours / yours it took for the
  bar) and write both numbers in the lessons.
- **Fix only the BIGGEST GAP**, at its cause, radically — one cause, one change. A BLOCKING fault
  the critic marks as a one-line fix may ride along.
- Next round = a **NEW critic**, same moments + the last report.
- **The pass is done when its exit list is true AND a critic answers `VERDICT: YES` with no
  BLOCKING fault.**
- **The same fault twice** means the fix was the wrong kind: change the method, not the amount
  (geometry instead of a texture, a real light instead of a brighter grade, another camera).
- The director's review between passes never replaces critic rounds.
*(SKILL references/critic.md)*

## 4. Hard rules

- **Made new from this voice:** cast, acting, shots, camera and set are written for this film.
  Examples teach the method and set the bar; they are never copied as material.
- **Open on a character's face**, scared or expressive, in the first frame. Never an empty scene,
  never a back.
- **Pure in t:** every frame is a function of t alone. No `Math.random` (use a seeded generator),
  no `Date`, no state between frames.
- **Never edit the engine copy** (`engine/`, `world/`, `lib/`, `specs/`). New looks, sets, props
  and characters go in `scenes/`. If an engine change seems needed, work around it and record it
  in the lessons as a gap.
- **Never touch `audio/`.** Voice lines are written as heard.
- **Anything in a place is in every shot of it.** Faces read: within about 60° of the camera, big,
  never cut by the edge.
- **PROP GUARD:** a prop that jumps on screen fails the film. `pick_up`, `put_down`, hand-overs,
  place changes on cuts, `snap` on real hits.
- **Later passes never change what earlier passes made** unless that is their job.
- Stay inside the project. Pictures only through `make_picture`; never a paid service the member
  did not choose.
*(SKILL, "Hard rules")*

## 5. The set bar — measured, and export refuses below it

`film_check { kind: 'set' }`, measured by the app: a shot needs **≥ 22 % detailed set** and
**≤ 80 % flat**; the film needs a **median shot of ≥ 28 % detail** and **≤ 78 % flat**, with
**no more than 40 % of its shots under**. Environment, Post and Shading cannot finish below it,
and **the app's export calls a film below it unfinished**. *(SKILL, "Hard rules")*

## 6. Quality has no clock

"A pass is done when its exit list is true AND a fresh critic says YES. Never cut a beat, a
character, a set piece or an effect to finish; never turn an effect down until it is gone to make
a problem disappear." Only the app's FASTER BUILDS block, when the member turned it on, speaks
about time. *(SKILL, "Quality first")* The bar is the LOOK, never the subject: any topic reaches
the same depth, light, air and acting with its own places. *(SKILL, "The bar")*

## 7. Voice and words

- The voice is law: `audio/clean.wav` + `audio/clean.json` (the trimmed voice and its word times)
  are **made by the app: never edit**. *(SKILL, project table)*
- Audio step 1 — tighten pauses without damaging the voice (`pipeline-scripts/audio_prep.py`):
  a pause = RMS below **−50 dB** for ≥ 0.12 s; word tails/onsets found at **−62 dB** with a 25 ms
  guard each side; only the middle of the silence is removed, each pause keeps **110–200 ms** so
  sentence rhythm survives; every join gets a **20 ms equal-power crossfade**; peak-normalised to
  **−1 dBFS**; output 48 kHz mono + a cuts report with a click test at every join.
- Step 2 — transcribe (`transcribe.py`): the raw transcript is only a draft; a human/agent reads
  it and fixes proper nouns, numbers and homophones into `audio/transcript.txt` — **align.py
  force-aligns that exact text, so what is written there is what the timings and captions
  contain.**
- Step 3 — align (`align.py`): forced alignment → snap to waveform → pause anchoring (every real
  pause, < −50 dB ≥ 90 ms, must fall BETWEEN words) → phrases from the audio's own voiced regions
  → an independent per-phrase re-transcription check → false-pause merging. Outputs
  `audio/timeline.json`, `audio/script_timed.txt` (the storyboard source), `audio/captions.srt`,
  `audio/align_report.json`.

## 8. Sound design and the mix — pass criteria

- Beds/SFX are **synthesized procedurally, no samples, no licensing** (`sound_design.py`):
  beds high-passed at **40 Hz**, soft-limited at **−20 dBFS**; noise beds low-passed; no tonal
  whines above ~1 kHz; **2.5 s crossfades** between beds; bed gains are target RMS **−29…−32 dBFS**
  (the tasteful range) before the −4 dB global trim.
- Lanes (`lanes_mix.py`): every clip on its lane (trimmed, looped, faded, panned, levelled,
  **ducked under the voice**), per-lane EQ + glue compression, one shared room reverb, effects
  bus through a gentle limiter; voice-activity for ducking is measured in 10 ms blocks at
  −45…−30 dBFS.
- Final mix (`mix.py`) **pass criteria, printed in `audio/mix_report.json`**: voice-to-bed ratio
  while speaking **≥ 16 dB** (`--min-ratio`; style variants: stick-story 12, because its
  references sit 10–13 LU under the voice); **true peak ≤ −1.0 dB** (mix step's own ceiling
  default −1.5 dB; low-poly −2 dB); **integrated loudness within 0.5 LU of target**, target
  default **−16 LUFS** (loudnorm LRA = 11). If the ratio is too low: **lower the gains in
  beds.json and re-run sound_design — do not touch the voice.** Bed duck sidechain default 3.0
  (low-poly 1.5, effects stay audible). The user's own music is first levelled to −16 LUFS so its
  dB setting means the same for any track, then ducked (default 8 dB) under the voice.

  if (!walks.length) return [base[0], 0, base[1]];

  let remain = Math.max(0, t - w.t0) * speed;
  for (let i=1;i<path.length;i++) {
    const a=path[i-1], b=path[i], d=Math.hypot(b[0]-a[0],b[1]-a[1]);
