- Pixel gate (driver-authored reference) — three defects found by Astra's review (2026-11-23, phase 11): (1) pixel_measure.py CLAMPS expanded disc bounds to the image, making audit_pixels' "disc crosses edge by >24px" check dead code — crop verdicts actually rest on the skin-touch test alone; preserve UNCLIPPED bounds for the cross check. (2) Pair detection passes on one large segmented region — it must match BOTH named characters' discs before passing a two-face moment. (3) Measured-disc overlap has no depth test — an occluder must be CLOSER (larger/nearer disc or z evidence), not merely overlapping, or background discs false-fail occlusion. Any re-derivation must fix all three and still reproduce the validation table.
- Projected bbox "frame share" from a camera sampler does NOT account for occlusion: F590 round 2's sea-plane share read 23.8% in projection but ~7% in the render (the wall and village occlude most of the plane). Treat projected shares of large background planes as upper bounds, never as the frame's measured composition; the pixel gate on the still is the composition judge.
- Astra batch-2 method adoptions (2026-11-23): (1) STANDING: approve staging with projected evidence, then approve the result with rendered pixels — neither substitutes for the other. (2) An occlusion explanation must account for EVERY hidden glyph: "5M" visible from "15.5M" means "15." is covered, not just "1" — check the kind's source text first (camera moves cannot repair wrong underlying text), then confirm the full inscription on the post-fix still. (3) A head disc out of frame does not prove palm/arm coverage — check the named body part specifically. (4) Occupancy-style measurements use the rendered cluster's aggregate bounds from the sampled eased camera + state at t, never the origin proxy box or the authored TO pose. (5) Composition root causes to name before computing: inverted subject hierarchy (SH04 — protect the lead's screen region), wrong side of the occluding surface (F474 — establishing beats go village-side oblique), uniform-sky allocation (SH11 — layered roofline low, clear corridor high).
# Production and rules — the operating law of the heart

This folder is the complete Creatorize Suite **0.28.3**, fully extracted (see `COMPLETENESS.md` and
`EXTRACTION.md`). The heart — the main-process core — is at
`suite-win-portable/app.asar.extracted/out/main/index.js`, with its Python pipeline spine at
`suite-win-portable/app.asar.extracted/pipeline-scripts/`. The rules below are distilled **only**
from the extracted files themselves; each rule names its source. Nothing here is imported from
outside the heart.

The flagship method is the cartoon-shorts skill
(`suite-win-portable/resources/templates/skill/cartoon-shorts/SKILL.md`); the other 18 skills carry
the same discipline per style/engine. Where a rule comes from that skill it is cited as *(SKILL)*.

## 1. The five passes — order is law

Every film is built in five passes, in this order, each run from its own step file, each standing
alone and keeping what the others made. "End to end" = the five in that order, with the director's
whole-film review between them. *(SKILL, "The stages")*

| # | Pass | Step file | Exit (summary; the full list is in the step file) |
|---|---|---|---|
| 1 | Build | `steps/build.md` | Frame 0 an expressive face; every word in a line; PROP GUARD passes; critic YES |
| 2 | Camera angles | `steps/camera.md` | Every fast move clean on a full-rate strip; `film_check same` passes; critic YES |
| 3 | Environment overhaul | `steps/environment.md` | The set bar passes; depth behind every face; critic YES |
| 4 | Add post processing | `steps/post.md` | Numbers per place class; faces the sharpest thing; set bar still passes; critic YES |
| 5 | Shading pass | `steps/shading.md` | `shade_jumps`/`calm` looked at; set bar still passes; critic YES |

Priority inside the work, the owner's words: **characters first** ("they are what makes the whole
thing feel alive"), **then the camera, the set, the post, the light**. *(SKILL, "Your role")*

## 2. How every pass runs — the loop

1. **Read** the step file, its named references, every earlier pass's `lessons/*.md` HANDOVER, the
   bar stills, and the guide pages for this pass (always pages 01 and 10).
2. **Before touching anything:** `render_frames` at `scale: 1` on 4–6 key times + a whole-film
   `film_sheet`. Write the gap list — what the bar has that these frames lack, worst first.
3. **Work:** change something real, `check_preview`, LOOK (`film_sheet`, `strip` on fast moves,
   `render_frames` on faces). Fix the worst thing radically, at its cause. Again.
4. **Machine checks** of the pass: every FAIL fixed at its cause. *Numbers point, eyes decide.*
5. **Critic rounds** (see §3). 6. **Handover:** `lessons/<step>.md`, ending with the HANDOVER block.
*(SKILL, "How every pass runs")*

## 3. Critic discipline — you never grade your own work

- Every pass ends with critic rounds: a **new** agent that never saw your reasoning sees your
  frames **blind-mixed with bar frames** (same size, shuffled, neutral names; the key file is
  never shown to the critic) and answers in a fixed form.
- Read the answer; count the blind score (bar pictures it took for yours / yours it took for the
  bar) and write both numbers in the lessons.
- **Fix only the BIGGEST GAP**, at its cause, radically — one cause, one change. A BLOCKING fault
  the critic marks as a one-line fix may ride along.
- Next round = a **NEW critic**, same moments + the last report.
- **The pass is done when its exit list is true AND a critic answers `VERDICT: YES` with no
  BLOCKING fault.**
- **The same fault twice** means the fix was the wrong kind: change the method, not the amount
  (geometry instead of a texture, a real light instead of a brighter grade, another camera).
- The director's review between passes never replaces critic rounds.
*(SKILL references/critic.md)*

## 4. Hard rules

- **Made new from this voice:** cast, acting, shots, camera and set are written for this film.
  Examples teach the method and set the bar; they are never copied as material.
- **Open on a character's face**, scared or expressive, in the first frame. Never an empty scene,
  never a back.
- **Pure in t:** every frame is a function of t alone. No `Math.random` (use a seeded generator),
  no `Date`, no state between frames.
- **Never edit the engine copy** (`engine/`, `world/`, `lib/`, `specs/`). New looks, sets, props
  and characters go in `scenes/`. If an engine change seems needed, work around it and record it
  in the lessons as a gap.
- **Never touch `audio/`.** Voice lines are written as heard.
- **Anything in a place is in every shot of it.** Faces read: within about 60° of the camera, big,
  never cut by the edge.
- **PROP GUARD:** a prop that jumps on screen fails the film. `pick_up`, `put_down`, hand-overs,
  place changes on cuts, `snap` on real hits.
- **Later passes never change what earlier passes made** unless that is their job.
- Stay inside the project. Pictures only through `make_picture`; never a paid service the member
  did not choose.
*(SKILL, "Hard rules")*

## 5. The set bar — measured, and export refuses below it

`film_check { kind: 'set' }`, measured by the app: a shot needs **≥ 22 % detailed set** and
**≤ 80 % flat**; the film needs a **median shot of ≥ 28 % detail** and **≤ 78 % flat**, with
**no more than 40 % of its shots under**. Environment, Post and Shading cannot finish below it,
and **the app's export calls a film below it unfinished**. *(SKILL, "Hard rules")*

## 6. Quality has no clock

"A pass is done when its exit list is true AND a fresh critic says YES. Never cut a beat, a
character, a set piece or an effect to finish; never turn an effect down until it is gone to make
a problem disappear." Only the app's FASTER BUILDS block, when the member turned it on, speaks
about time. *(SKILL, "Quality first")* The bar is the LOOK, never the subject: any topic reaches
the same depth, light, air and acting with its own places. *(SKILL, "The bar")*

## 7. Voice and words

- The voice is law: `audio/clean.wav` + `audio/clean.json` (the trimmed voice and its word times)
  are **made by the app: never edit**. *(SKILL, project table)*
- Audio step 1 — tighten pauses without damaging the voice (`pipeline-scripts/audio_prep.py`):
  a pause = RMS below **−50 dB** for ≥ 0.12 s; word tails/onsets found at **−62 dB** with a 25 ms
  guard each side; only the middle of the silence is removed, each pause keeps **110–200 ms** so
  sentence rhythm survives; every join gets a **20 ms equal-power crossfade**; peak-normalised to
  **−1 dBFS**; output 48 kHz mono + a cuts report with a click test at every join.
- Step 2 — transcribe (`transcribe.py`): the raw transcript is only a draft; a human/agent reads
  it and fixes proper nouns, numbers and homophones into `audio/transcript.txt` — **align.py
  force-aligns that exact text, so what is written there is what the timings and captions
  contain.**
- Step 3 — align (`align.py`): forced alignment → snap to waveform → pause anchoring (every real
  pause, < −50 dB ≥ 90 ms, must fall BETWEEN words) → phrases from the audio's own voiced regions
  → an independent per-phrase re-transcription check → false-pause merging. Outputs
  `audio/timeline.json`, `audio/script_timed.txt` (the storyboard source), `audio/captions.srt`,
  `audio/align_report.json`.

## 8. Sound design and the mix — pass criteria

- Beds/SFX are **synthesized procedurally, no samples, no licensing** (`sound_design.py`):
  beds high-passed at **40 Hz**, soft-limited at **−20 dBFS**; noise beds low-passed; no tonal
  whines above ~1 kHz; **2.5 s crossfades** between beds; bed gains are target RMS **−29…−32 dBFS**
  (the tasteful range) before the −4 dB global trim.
- Lanes (`lanes_mix.py`): every clip on its lane (trimmed, looped, faded, panned, levelled,
  **ducked under the voice**), per-lane EQ + glue compression, one shared room reverb, effects
  bus through a gentle limiter; voice-activity for ducking is measured in 10 ms blocks at
  −45…−30 dBFS.
- Final mix (`mix.py`) **pass criteria, printed in `audio/mix_report.json`**: voice-to-bed ratio
  while speaking **≥ 16 dB** (`--min-ratio`; style variants: stick-story 12, because its
  references sit 10–13 LU under the voice); **true peak ≤ −1.0 dB** (mix step's own ceiling
  default −1.5 dB; low-poly −2 dB); **integrated loudness within 0.5 LU of target**, target
  default **−16 LUFS** (loudnorm LRA = 11). If the ratio is too low: **lower the gains in
  beds.json and re-run sound_design — do not touch the voice.** Bed duck sidechain default 3.0
  (low-poly 1.5, effects stay audible). The user's own music is first levelled to −16 LUFS so its
  dB setting means the same for any track, then ducked (default 8 dB) under the voice.

"""Pixel measurements for one probed still (fudai-wall pixel gate).

Usage: pixel_measure.py <still.png>
Prints one JSON object:
  flat_pct / detail_pct  - RULES S5 block measure: 32x32 blocks on grayscale;
                           flat block = std < 5, detail block = std >= 12.
  discs                  - rendered head discs found by skin segmentation:
                           a skin component ringed by the characters' dark
                           outline. Each disc: skin bbox, expanded bbox
                           (outline + hair/hat allowance, +12% per side),
                           area, dark-adjacency ratio.
Calibration (2026-11-23, chunk2d stills): F537 mocker silhouette 648x624 px
vs the staging audit's 480 px model disc (1.32x, hat-inclusive); F687 mayor
disc centre (553,30) r~473 vs projected (540,653) r448 - the gate therefore
MEASURES discs in the image instead of trusting projected centres.
"""
import json, sys
import numpy as np
from PIL import Image
from scipy import ndimage

def components(mask):
    lab, n = ndimage.label(mask)
    return lab, n

def main():
    path = sys.argv[1]
    img = Image.open(path).convert('RGB')
    a = np.asarray(img).astype(np.int32)
    H, W = a.shape[:2]
    R, G, B = a[:, :, 0], a[:, :, 1], a[:, :, 2]

    # ---- S5 block measure (grayscale, 32x32 blocks) ----
    gray = (0.299 * R + 0.587 * G + 0.114 * B)
    bs = 32
    nb = 0; flat = 0; detail = 0
    for y in range(0, H - bs + 1, bs):
        for x in range(0, W - bs + 1, bs):
            s = gray[y:y + bs, x:x + bs].std()
            nb += 1
            if s < 5: flat += 1
            if s >= 12: detail += 1
    flat_pct = round(100.0 * flat / nb, 1)
    detail_pct = round(100.0 * detail / nb, 1)

    # ---- head discs: skin mask + dark-outline adjacency ----
    skin = (R > 130) & (R - B > 25) & (R - G > 8) & (R - G < 95) & (G - B > 5) & (G - B < 80)
    dark = (R < 85) & (G < 75) & (B < 75)
    lab, n = components(skin)
    discs = []
    if n:
        for root in range(1, n + 1):
            m = lab == root
            area = int(m.sum())
            if area < 6000:
                continue
            ys, xs = np.nonzero(m)
            x0, x1, y0, y1 = int(xs.min()), int(xs.max()), int(ys.min()), int(ys.max())
            # dark adjacency: dilate by 3 px, ring = dilated & ~m
            d = ndimage.binary_dilation(m, iterations=3)
            ring = d & ~m
            ring_n = int(ring.sum())
            adj = float((ring & dark).sum()) / ring_n if ring_n else 0.0
            bw, bh = x1 - x0 + 1, y1 - y0 + 1
            aspect = bw / max(bh, 1)
            if adj < 0.30 or not (0.55 <= aspect <= 2.3):
                continue
            ex = round(bw * 0.12); ey = round(bh * 0.12)
            discs.append({
                'skin': [x0, y0, x1, y1],
                'disc': [max(0, x0 - ex), max(0, y0 - ey), min(W - 1, x1 + ex), min(H - 1, y1 + ey)],
                'centre': [round((x0 + x1) / 2), round((y0 + y1) / 2)],
                'area': area, 'adj': round(adj, 2),
            })
    discs.sort(key=lambda d: -d['area'])
    print(json.dumps({'file': path, 'size': [W, H], 'flat_pct': flat_pct,
                      'detail_pct': detail_pct, 'discs': discs}))

const vtok = s => String(s).normalize('NFKD').replace(/\p{M}+/gu, '').toLowerCase().replace(/[’']/g, '').replace(/[-–—/]/g, ' ').replace(/[^\p{L}\p{N} ]+/gu, ' ').split(/\s+/).filter(Boolean);
const TTS_DROPPED = new Set(['pfft', 'tsk', 'tut']);
const JOIN_MAX = 40;   // a line token written without spaces (Japanese, Chinese, Thai) is several transcript words: join up to this many
export function splitOwnWords(words, lines, cast = {}) {
  const ws = words.filter(w => vtok(w.word).length);
  let j = 0; const outW = [], outL = [];
  lines.forEach((L, i) => {
    const n = i + 1, who = L.who != null && L.who in cast ? L.who : null, toks = vtok(L.text || '');
    const mine = [];
    for (const tk of toks) {
      const w = ws[j];
      const got = w ? vtok(w.word).join('') : null;
      if (got === tk) { mine.push(w); j++; continue; }
      if (TTS_DROPPED.has(tk)) continue;
      // a transcript can split / join a word differently (e.g. "o clock" vs "oclock", or a Japanese clause heard as several words):
      // join the next words while they spell the start of the token (two words = the old rule, unchanged)
      if (w && ws[j + 1] && tk.startsWith(got)) {
        let acc = got, k = j + 1, word = w.word;
        while (ws[k] && k - j < JOIN_MAX && acc.length < tk.length) { const nx = acc + vtok(ws[k].word).join(''); if (!tk.startsWith(nx)) break; acc = nx; word += ws[k].word; k++; }
        if (acc === tk) { mine.push({ ...w, word, end: ws[k - 1].end }); j = k; continue; }
      }
      throw new Error(`MAKE_FILM FAILED: voice file: line ${n} ("${L.text}") expects "${tk}" but words.json has ${w ? `"${w.word}" at ${w.start}s (word ${j + 1})` : 'no more words'}. ${outW.length} words matched before it.`);
    }
    if (!mine.length) throw new Error(`MAKE_FILM FAILED: voice file: line ${n} ("${L.text}") has no words`);
    for (const w of mine) outW.push({ who, line: n, word: w.word, start: +w.start, end: +w.end });
    outL.push({ line: n, who, text: L.text, start: +mine[0].start, end: +mine[mine.length - 1].end, ...(L.loud ? { loud: true } : {}) });
  });
  if (j < ws.length) throw new Error(`MAKE_FILM FAILED: voice file: words.json has ${ws.length - j} words after the last line (from "${ws[j].word}" at ${ws[j].start}s): add the missing line(s)`);
  return { words: outW, lines: outL };
}

// ---- 'line:2.word:3+0.1' -> seconds on the film clock (= the voice clock). FX1: any string value starting with 'line:' in acts / props /

export const TIME_KEYS = new Set(['t', 't0', 't1', 'parkAt']);
export function resolver(voice) {
  return (ref, where) => {
    if (typeof ref !== 'string') return ref;
    const at = where ? ` at ${where}` : '';
    const m = ref.match(/^line:(\d+)(?:\.(start|end)|\.word:(\d+)(?:\.(start|end))?)?\s*([+-]\s*[\d.]+)?$/);
    if (!m) throw new Error(`MAKE_FILM FAILED: bad time "${ref}"${at} (seconds, or line:N.start | line:N.end | line:N.word:K[.end] [+-s])`);
    const L = voice.lines.find(l => l.line === +m[1]);
    if (!L) throw new Error(`MAKE_FILM FAILED: "${ref}"${at}: no line ${m[1]} (the film has ${voice.lines.length} lines)`);
    let t;
    if (m[3]) { const ws = voice.words.filter(w => w.line === +m[1]); const w = ws[+m[3] - 1]; if (!w) throw new Error(`MAKE_FILM FAILED: "${ref}"${at}: line ${m[1]} has ${ws.length} words`); t = m[4] === 'end' ? w.end : w.start; }
    else t = m[2] === 'end' ? L.end : L.start;
    return +(t + (m[5] ? +m[5].replace(/\s/g, '') : 0)).toFixed(4);
  };
}
const NOTIME = new Set(['text', '_n', '_doc', 'name', 'kind', 'id', 'who', 'owner', 'spec', 'in', 'move', 'ease', 'gait', 'mouth', 'eyes', 'brow']);
export function resolveTimes(x, R, where = '') {
  const isLine = v => typeof v === 'string' && /^\s*line:/.test(v);
  if (Array.isArray(x)) return x.map((v, i) => isLine(v) ? R(v.trim(), `${where}[${i}]`) : resolveTimes(v, R, `${where}[${i}]`));
  if (!x || typeof x !== 'object') return x;
  const o = {};
  for (const [k, v] of Object.entries(x)) {
    const p = where ? `${where}.${k}` : k;
    if (TIME_KEYS.has(k) && typeof v === 'string') o[k] = R(v.trim(), p);
    else if (TIME_KEYS.has(k) && v != null && typeof v !== 'number' && typeof v !== 'function') throw new Error(`MAKE_FILM FAILED: ${p} = ${JSON.stringify(v)} is not a time (seconds or 'line:N...')`);

  }
  return o;
}

// ---- ENG5 / ENG6 (see tools/make_film.mjs history): never a frozen frame. park -> slow dolly; push whose ease stops dead at a shot edge ->
// padded past it; follow + parkAt -> follow, then a park on its parked framing (with the drift). still/park: true or drift: false = as authored.
export async function autoMove(shots, dur, opts = {}) {
  if (opts.rootOf) shots = await splitFollows(shots, dur, opts.rootOf);
  const sub = (a, b) => a.map((v, i) => v - b[i]), addk = (a, d, k) => a.map((v, i) => v + d[i] * k);
  return shots.map((s, i) => {
    const c = s.camera || {}, a = s.t0 ?? 0;
    const b = Math.min(s.t1 ?? Infinity, shots[i + 1]?.t0 ?? Infinity, dur);
    if (s.still === true || c.still === true || s.park === true || c.park === true || c.drift === false || s.drift === false || !(b > a + 1 / 30)) return s;
    const m = c.move || 'park', L = b - a;
    if (m === 'park' && Array.isArray(c.pos) && Array.isArray(c.target)) {
      const rate = c.drift ?? s.drift ?? .02, frac = Math.min(.15, rate * L), dir = sub(c.target, c.pos), e = easeFn('inOutSine');
      const pad = L / 2, k0 = pad / (L + 2 * pad), span = e(1 - k0) - e(k0);
      const P = u => addk(c.pos, dir, frac * (u - e(k0)) / span);
      return { ...s, camera: { ...c, move: 'push', from: { pos: P(0), target: [...c.target], fov: c.fov ?? 26 }, to: { pos: P(1), target: [...c.target], fov: c.fov ?? 26 },
        t0: a - pad, t1: b + pad, ease: 'inOutSine', _auto: 'drift' } };
    }
    if (m === 'push' && c.from?.pos && c.to?.pos && typeof (c.ease ?? 'outCubic') === 'string') {
      const e = easeFn(c.ease || 'outCubic'), p0 = c.t0 ?? a, p1 = c.t1 ?? (s.t1 ?? b);
      if (!(p1 > p0)) return s;
      const slow0 = (e(.03) - e(0)) / .03 < .35, slow1 = (e(1) - e(.97)) / .03 < .35;
      const pad0 = slow0 && p0 <= a + 1 / 30 ? 1 : 0, pad1 = slow1 && Math.abs(p1 - b) <= 1 / 30 ? 1 : 0;
      if (!pad0 && !pad1) return s;
      const PL = p1 - p0, padL = (pad0 && pad1 ? .35 : .6) * PL, q0 = p0 - pad0 * padL, q1 = p1 + pad1 * padL;
      const ka = e((p0 - q0) / (q1 - q0)), kb = e((p1 - q0) / (q1 - q0));
      const fix = (A, B) => { if (!Array.isArray(A) || !Array.isArray(B)) return [A, B]; const D = sub(B, A).map(v => v / (kb - ka)); const F0 = addk(A, D, -ka); return [F0, addk(F0, D, 1)]; };
      const [pf, pt] = fix(c.from.pos, c.to.pos), [tf, tt] = fix(c.from.target ?? c.to.target, c.to.target ?? c.from.target);
      const f0 = c.from.fov ?? 26, f1 = c.to.fov ?? f0, fd = (f1 - f0) / (kb - ka);
      return { ...s, camera: { ...c, from: { ...c.from, pos: pf, target: tf, fov: f0 - fd * ka }, to: { ...c.to, pos: pt, target: tt, fov: f0 - fd * ka + fd }, t0: q0, t1: q1, _auto: 'pad' } };
    }
    return s;
  });
}
async function splitFollows(shots, dur, rootOf) {
  const out = [];
  shots.forEach((s, i) => {
    const c = s.camera || {}, a = s.t0 ?? 0, b = Math.min(s.t1 ?? Infinity, shots[i + 1]?.t0 ?? Infinity, dur), pk = c.parkAt;
    if (c.move !== 'follow' || typeof pk !== 'number' || !c.who || !(pk > a + 1 / 30) || !(b > pk + 1 / 30)
      || s.still === true || c.still === true || s.park === true || c.park === true || c.drift === false || s.drift === false) { out.push(s); return; }
    const off = c.offset || [0, 0, 0];
    const subj = t => { const r = rootOf(c.who, t); return [r[0] + (off[0] || 0), r[1] + (off[1] || 0), r[2] + (off[2] || 0)]; };
    const P = follow(subj, { offset: c.camOffset || [0, 2, 9], lag: c.lag ?? .3, fov: c.fov ?? 26, lookOffset: c.look || [0, 1.4, 0] })(pk);
    let r0 = c.roll, r1 = c.roll;
    if (Array.isArray(c.roll)) { const end = b > 90 ? a + 4 : b, x = Math.min(1, Math.max(0, (pk - a) / Math.max(.01, end - a))), k = x * x * (3 - 2 * x);
      const rm = c.roll[0] + (c.roll[1] - c.roll[0]) * k; r0 = [c.roll[0], rm]; r1 = [rm, c.roll[1]]; }
    out.push({ ...s, t1: pk, camera: { ...c, ...(r0 != null ? { roll: r0 } : {}) } });
    out.push({ ...s, t0: pk, t1: s.t1 ?? b, _parkOf: i, camera: { move: 'park', pos: P.pos, target: P.target, fov: P.fov, ...(r1 != null ? { roll: r1 } : {}), ...(c.drift != null ? { drift: c.drift } : {}) } });
  });
  return out;
}
/** rests of every character from one tiny stage (io.openStage) */
async function restsFrom(characters, openStage) {
  const st = await openStage({ width: 64, height: 64, grid: false, characters: characters.map(c => ({ name: c.name, spec: c.spec, timeline: c.timeline })),
    camera: { keys: [{ t: 0, pos: [0, 2, 10], target: [0, 2, 0], fov: 26 }] } }, {});
  const rests = {}; st.info.chars.forEach((c, i) => { rests[characters[i].name] = c.rest; });
  await st.close();
  return rests;
}
/** rootOf(who, t) -> [x, y, z] from the characters' timelines, for autoMove's follow split */
async function rootsFor(characters, openStage) {
  const rests = await restsFrom(characters, openStage);
  return (who, t) => { const c = characters.find(x => x.name === who || x.spec?.id === who || x.spec === who); if (!c || !rests[c.name]) return [0, 0, 0];
    const p = evalPose(c.timeline, t, rests[c.name]); return [p.root.x || 0, p.root.y || 0, p.root.z || 0]; };
}

// ---- FIX1 PROPS / PROPS2: one owner per prop at every frame, checked before anything renders (see FILM_API "props").
export function propOwners(scene, film, fps = 30) {
  const cast = new Set(Object.keys(film.cast || {})), cuts = (scene.shots || []).map(s => s.t0 ?? 0);
  const onCut = t => cuts.some(c => Math.abs(c - t) <= 1.01 / fps);
  const ownerAt = (p, t) => { let o = p.owner; for (const k of p.keys || []) if (k.t <= t + 1e-6 && k.owner) o = k.owner; return o; };
  const inAt = (p, t) => { let w = p.in || 'world'; for (const k of p.keys || []) if (k.t < t - 1e-6 && k.in) w = k.in; return w; };
  const swapWith = (p, k, dir) => (scene.props || []).some(q => q !== p && (q.keys || []).some(x => Math.abs(x.t - k.t) <= 1.01 / fps &&
    ownerAt(q, x.t) === ownerAt(p, k.t) && (dir === 'hide' ? /^hand:/.test(x.in || '') && inAt(q, x.t) === 'hidden' : x.in === 'hidden' && /^hand:/.test(inAt(q, x.t)))));
  for (const p of scene.props || []) {
    for (const k of p.keys || []) if (k.t >= 0 && /^hand:/.test(k.in || '') && inAt(p, k.t) === 'hidden' && !k.fetch && !onCut(k.t) && !swapWith(p, k, 'show'))
      throw new Error(`MAKE_FILM FAILED: prop "${p.id}" key at t ${(+k.t).toFixed(2)} (f${Math.round(k.t * fps)}) makes the prop APPEAR in ${k.in} inside a shot (it pops into the hand): show it on a cut, swap it for a prop leaving that hand at the same t, or have a hand take it on screen (pick_up / a hand-over) and mark the key fetch: true`);
    const steps = [{ t: -1, owner: p.owner, in: p.in || 'world', at: p.at }, ...(p.keys || []).filter(k => !k.optsOnly && ['in', 'owner', 'at', 'drop'].some(f => f in k))];
    let cur = { owner: p.owner, in: p.in || 'world', at: p.at };
    for (const k of steps) {
      cur = { owner: k.owner ?? cur.owner, in: k.in ?? (k.at && !k.owner ? cur.in : cur.in), at: k.at ?? cur.at };
      const where = `prop "${p.id}"${k.t >= 0 ? ` key at t ${(+k.t).toFixed(2)} (f${Math.round(k.t * fps)})` : ''}`;
      if (k.drop) continue;
      if (/^hand:|^body$/.test(cur.in) && !cast.has(cur.owner)) throw new Error(`MAKE_FILM FAILED: ${where} is in ${cur.in} but has no owner in the cast (owner ${JSON.stringify(cur.owner)}): give it an owner, or a world at`);
      if (cur.in === 'world' && !Array.isArray(cur.at) && !cast.has(cur.owner)) throw new Error(`MAKE_FILM FAILED: ${where} has no owner: not in a hand and no world at [x, y, z]`);
      if (k.t >= 0 && k.in === 'hidden' && !k.stow && !onCut(k.t) && !swapWith(p, k, 'hide'))
        throw new Error(`MAKE_FILM FAILED: ${where} hides the prop inside a shot (it would vanish on screen): hide it on a cut, or put it away with a hand (put_down / pocket) and mark the key stow: true`);
    }
  }
}

// ---- AGENT-A: grab_collar needs the TARGET's collar in world at every frame (params._track), + the target's jerk on contact.
export function collarPoint(P, r, toward, hhf) {
  const top = (P.root.y || 0) + P.body.hipY + hhf(r) - .5 - .14;
  const dx = toward[0] - P.root.x, dz = toward[2] - P.root.z, d = Math.hypot(dx, dz) || 1;
  const out = .2;
  return [+(P.root.x + dx / d * out).toFixed(4), +top.toFixed(4), +(P.root.z + dz / d * out).toFixed(4)];
}
async function collarTracks(film, characters, voice, io, log) {
  const isGrab = x => (x.name ?? x.clip) === 'grab_collar';
  const todo = []; for (const c of characters) for (const x of c.timeline.clips || []) if (isGrab(x)) todo.push({ c, x });
  if (!todo.length) return;
  const rests = await FE.restsOf(characters, io.openStage);
  const bare = c => ({ ...c.timeline, clips: (c.timeline.clips || []).filter(x => !isGrab(x)) });
  const horizon = film.duration ?? Math.min(90, (voice.lines.length ? Math.max(...voice.lines.map(l => l.end)) : 0) + (film.tail ?? 1.6) + 2);
  for (const { c, x } of todo) {
    const p = x.params || (x.params = {}), tg = characters.find(o => o.name === p.target);
    if (!tg) throw new Error(`MAKE_FILM FAILED: acts.${c.name} grab_collar: params.target "${p.target}" is not in the cast (${characters.map(o => o.name).join(', ')})`);
    const t0 = x.t0 ?? 0, rT = rests[tg.name], rG = rests[c.name], tlG = bare(c), tr = [];
    const g = evalPose(tlG, t0, rG).root;
    if (p.jerk !== false) {
      const tc = t0 + (p.reach ?? 5) / 30, PT = evalPose(bare(tg), tc, rT), dx = g.x - PT.root.x, dz = g.z - PT.root.z, d = Math.hypot(dx, dz) || 1;
      (tg.timeline.clips ||= []).push({ name: 'collar_jerk', t0: +(tc - 1 / 30).toFixed(4), params: { dx: +(dx / d * .08).toFixed(4), dz: +(dz / d * .08).toFixed(4) }, _auto: true });
    }
    const tlT = bare(tg);
    const end = p.release != null ? t0 + ((p.reach ?? 5) + p.release + 6) / 30 : Math.max(t0 + 1, horizon);
    for (let f = 0; t0 + f / 30 <= end + 1e-9; f++) {
      const t = t0 + f / 30, PT = evalPose(tlT, t, rT), PG = evalPose(tlG, t, rG);
      tr.push([+(f / 30).toFixed(4), collarPoint(PT, rT, [PG.root.x, 0, PG.root.z], hh)]);
    }
    p._track = tr;
    const a = tr[0][1], dist = Math.hypot(a[0] - g.x, a[2] - g.z);
    log(`grab_collar: ${c.name} -> ${tg.name} at ${t0.toFixed(2)} s (${tr.length} frames tracked; collar ${dist.toFixed(2)} D from the grabber's root${dist > 1.3 ? ': FAR, the arm may not reach, stand closer' : ''})`);
  }
}
// ---- ENG4 listener gaze: during every line, each OTHER cast member's pupils go to the speaker's head (timeline base track listenGaze).
async function listenerGaze(film, characters, lines, io, log) {
  const todo = characters.filter(c => c.timeline.gaze !== false && film.cast[c.name]?.gaze !== false && !(c.timeline.base && 'listenGaze' in c.timeline.base));
  if (!todo.length) return;
  const rests = await restsFrom(characters, io.openStage);
  const headAt = (id, t) => { const c = characters.find(x => x.name === id), r = rests[id]; if (!c || !r) return null;
    const P = evalPose(c.timeline, t, r); return [+P.root.x.toFixed(3), +((P.root.y || 0) + P.body.hipY + hh(r)).toFixed(3), +P.root.z.toFixed(3)]; };
  let n = 0;
  for (const c of todo) {
    const looks = [...(c.timeline.look || []), ...(c.timeline.clips || []).filter(x => (x.name ?? x.clip) === 'look_at').map(x => ({ t: x.t0 ?? 0, gaze: x.params?.gaze, at: x.params?.at }))]
      .filter(k => typeof k.t === 'number').sort((a, b) => a.t - b.t);
    const keys = [[0, null, 'snap']];
    for (const L of lines) {
      if (L.who === c.name || !rests[L.who]) continue;
      if (looks.some(k => k.t >= L.start - .3 && k.t <= L.end)) continue;
      const last = looks.filter(k => k.t <= L.start).pop();
      if (last && last.at && last.gaze === 'hold') continue;
      const at = headAt(L.who, (L.start + L.end) / 2); if (!at) continue;
      keys.push([+(L.start + 2 / 30).toFixed(4), at, 'snap'], [+(L.end + .25).toFixed(4), null, 'snap']); n++;
    }
    if (keys.length > 1) c.timeline.base = { ...(c.timeline.base || {}), listenGaze: keys.sort((a, b) => a[0] - b[0]) };
  }
  log(`gaze: ${n} listener spans (pupils to the speaker)`);
}

// ---- ENG7 / ENG10: prop clips (eat / bite, pick_up, put_down) get owner, spots and bite keys (FILM_API "Eating, picking up, putting down").
const PROPCLIP = new Set(['eat', 'bite', 'pick_up', 'put_down']);
export function propClips(props, characters) {
  const byId = new Map((props || []).map(p => [p.id, p]));
  const bites = new Map();
  const puts = characters.flatMap(ch => (ch.timeline.clips || []).filter(s => (s.name ?? s.clip) === 'put_down' && s.params?.prop && Array.isArray(s.params.at))
    .map(s => ({ p: s.params.prop, at: s.params.at, t0: s.t0 ?? (typeof s.at === 'number' ? s.at : 0) }))).sort((a, b) => a.t0 - b.t0);
  for (const ch of characters) {
    const clips = (ch.timeline.clips || []).map(s => ({ s, t0: s.t0 ?? (typeof s.at === 'number' ? s.at : 0) })).sort((a, b) => a.t0 - b.t0);
    for (const { s, t0 } of clips) {
      const name = s.name ?? s.clip, p = s.params?.prop; if (!PROPCLIP.has(name) || !p) continue;
      const def = byId.get(p);
      if (!def) { console.log(`MAKE_FILM WARNING: acts.${ch.name} clip ${name} names prop "${p}" that the film's props list does not have`); continue; }
      if (def.owner == null && !(def.keys || []).some(k => 'owner' in k)) def.owner = ch.name;
      else if (def.owner != null && def.owner !== ch.name && !(def.keys || []).some(k => k.owner === ch.name))
        console.log(`MAKE_FILM WARNING: acts.${ch.name} clip ${name} moves prop "${p}" owned by "${def.owner}": the stage shows the owner's pose of it (hand it over first, or set owner)`);
      if (name === 'pick_up') {
        s.params = { ...s.params };
        const downs = puts.filter(x => x.p === p && x.t0 < t0 - 1e-9), last = downs[downs.length - 1];
        if (!s.params.at && last) s.params.at = [...last.at];
        if (!s.params.at) { if (!Array.isArray(def.at) || (def.in && def.in !== 'world')) throw new Error(`MAKE_FILM FAILED: acts.${ch.name} pick_up of "${p}" has no params.at and the prop has no world at`); s.params.at = [...def.at]; }
        if (!s.params.worldRot && !s.params.rot && Array.isArray(def.rot)) s.params.worldRot = [...def.rot];
      }
      if (name === 'put_down' && !s.params.worldRot && !s.params.rot && Array.isArray(def.rot)) s.params = { ...s.params, worldRot: [...def.rot] };
      if ((name === 'eat' || name === 'bite') && s.params.biteKey !== false) {
        const key = s.params.biteKey || 'bite', n = (bites.get(p) || 0) + 1; bites.set(p, n);
        const f = Math.max((s.params.up ?? 5) + 1, 6);
        def.keys = [...(def.keys || []), { t: +(t0 + f / 30).toFixed(4), [key]: s.params.biteTo ?? n, optsOnly: true }].sort((a, b) => a.t - b.t);
      }
    }
  }
}

// ---- FX1: a kit set's marks + seat height from world/sets.js's KIT table (plain text: no THREE needed), or a film's own set.js `marks: { ... }`
export function parseSetMarks(src, name, own) {
  const out = { marks: {}, seatY: null };
  if (src == null) return out;
  const i = own ? 0 : src.search(new RegExp(`\\n\\s*${name}: \\{`)); if (i < 0) return out;
  const nx = own ? -1 : src.slice(i + 1).search(/\n {2}[a-z_]+: \{\s*\n/); const block = src.slice(i, nx < 0 ? undefined : i + 1 + nx);
  const num = s => s.replace(/^(-?)\./, '$10.');
  const mk = block.match(/marks: \{([^}]*)\}/);
  if (mk) for (const m of mk[1].matchAll(/([A-Za-z_]\w*): \[\s*(-?[\d.]+),\s*(-?[\d.]+)\s*\]/g)) out.marks[m[1]] = [+num(m[2]), +num(m[3])];
  const sy = block.match(/seatY: (-?[\d.]+)/); if (sy) out.seatY = +num(sy[1]);
  return out;
}
async function setMarksIo(name, ownSet, io) {
  if (typeof name !== 'string' && !ownSet) return { marks: {}, seatY: null };
  let src = null; try { src = ownSet ? await io.text(ownSet.file, 'abs') : await io.text('world/sets.js', 'root'); } catch { src = null; }
  return parseSetMarks(src, name, !!ownSet);
}

// ---- ENG9: loud words (a script word ending in '!') -> facetime.js big mouths
const LOUD_TOK = /!["'”’)\]]*$/;
const normW = s => String(s).toLowerCase().replace(/[^\p{L}\p{N}]/gu, '');
export function loudWords(words = [], text = '') {
  const toks = String(text).split(/\s+/).filter(s => /[\p{L}\p{N}]/u.test(s)).map(s => ({ n: normW(s), loud: LOUD_TOK.test(s) }));
  let j = 0;
  return words.map((w, i) => {
    const n = normW(w.word);
    let k = -1;
    for (let q = j; q < Math.min(toks.length, j + 4); q++) if (toks[q].n === n) { k = q; break; }
    if (k < 0 && toks.length === words.length) k = i;
    if (k >= 0) j = k + 1;
    const loud = !!w.loud || (k >= 0 && toks[k].loud);
    return loud ? { ...w, loud: true } : { ...w };
  });
}
// ---- caption beats (his "words" style): one word, or two when they run together; never across a sentence end
const SENT_END = /[.?!]["'”’)]*$/;
const SPACELESS = /[฀-๿぀-ヿ㐀-鿿豈-﫿]/;
export function wordChunks(words, lines = []) {
  const out = [], endsSentence = new Set();
  const byLine = new Map(); words.forEach((w, i) => { if (!byLine.has(w.line)) byLine.set(w.line, []); byLine.get(w.line).push(i); });
  for (const [ln, idx] of byLine) {
    const L = lines.find(l => l.line === ln), toks = L ? L.text.split(/\s+/).filter(s => /[\p{L}\p{N}]/u.test(s)) : null;
    idx.forEach((wi, k) => { const tok = toks && toks.length === idx.length ? toks[k] : words[wi].word; if (SENT_END.test(tok)) endsSentence.add(wi); });
  }
  for (let i = 0; i < words.length;) {
    const a = words[i], b = words[i + 1];
    const two = b && !endsSentence.has(i) && b.line === a.line && (b.start - a.end < .2) && (a.word.length + b.word.length <= 11) && (a.word.length <= 4 || b.word.length <= 3);
    const ws = two ? [a, b] : [a];
    // (two Thai / Japanese / Chinese words join without a space: those languages write none between words)
    out.push({ t0: a.start, end: ws[ws.length - 1].end, line: a.line, who: a.who, text: ws.map(w => w.word).join(ws.every(w => SPACELESS.test(w.word)) ? '' : ' ').toUpperCase() });
    i += ws.length;
  }
  out.forEach((c, i) => { const n = out[i + 1]; c.t1 = n && n.line === c.line && n.t0 - c.end < .5 ? n.t0 : c.end + .3; });
  return out;
}
/** the caption at t (stage frame opts.caption): film.captions true | "line" = the spoken line, "words" = his big words; undefined = none */
export function captionFn(film, voice) {
  const chunks = film.captions === 'words' ? wordChunks(voice.words, voice.lines) : null;
  return t => {
    if (!film.captions) return undefined;
    if (chunks) { const c = chunks.find(c => t >= c.t0 - 1e-6 && t < c.t1); return c ? { text: c.text, style: 'words', age: t - c.t0, who: c.who } : ''; }
    const L = voice.lines.find(l => t >= l.start - .05 && t <= l.end + .25); return L ? L.text : '';
  };
}

// ---- the whole resolution (tools/make_film.mjs main(), up to resolved.json)
export async function resolveFilm(film, io, opts = {}) {
  const log = io.log || (() => {});
  const fps = film.fps || 30, [FW, FH] = film.size || [1080, 1920];
  const voice = await voiceOf(film, io, log), R = resolver(voice);
  if (opts.voiceOnly) return { voice };
  // acts: resolve times, add the voice's say tracks, the cast's start position, blinks
  const characters = [];
  let k = 0;
  for (const [id, c] of Object.entries(film.cast)) {
    const tl = resolveTimes(JSON.parse(JSON.stringify(film.acts?.[id] || {})), R, `acts.${id}`);
    tl.root = tl.root || { x: c.at?.[0] ?? 0, z: c.at?.[1] ?? 0, ry: c.ry ?? 0 };
    if (tl.root.y == null && (c.y ?? c.at?.[2]) != null) tl.root.y = c.y ?? c.at[2];
    const mine = voice.lines.filter(l => l.who === id);
    tl.say = [...(tl.say || []), ...mine.map(L => { const src = film.voice?.lines?.[L.line - 1] || {};
      const ws = loudWords(voice.words.filter(w => w.line === L.line), L.text ?? src.text ?? '');

// ---- PROP GUARD's allowed snaps (tools/make_film.mjs guardSnaps, line for line; the app's host page passes it as opts.guardSnaps so its
// film_probe tool judges teleports exactly as make_film does). A clip returning `hitFrame`, a clip entry `snap`, a prop key `{ t, snap: true }`:
// any size, one frame either side; the rest of a hitFrame clip's span up to .3 D a frame; a placement key's travel up to 1 D a frame.
export function guardSnaps(characters, props, CLIPS, rests, fps = 30) {
  const out = new Map(), put = (id, f, lim) => { const s = out.get(id) || new Map(); out.set(id, s); if (!(s.get(f) >= lim)) s.set(f, lim); };
  const add = (id, f) => { for (const d of [-1, 0, 1]) put(id, f + d, Infinity); };
  for (const c of characters) for (const x of c.timeline.clips || []) {
    const hits = [], name = x.name ?? x.clip, t0 = x.t0 ?? 0; let span = 0;
    try { const R = CLIPS[name]?.(rests[c.name], x.params || {}); if (R?.hitFrame != null) { hits.push(R.hitFrame); span = R.dur || 0; } } catch {}
    if (x.snap != null && x.snap !== true) hits.push(...[].concat(x.snap));
    if (!hits.length) continue;
    const ids = x.params?.prop ? [x.params.prop] : (props || []).filter(p => p.owner === c.name).map(p => p.id);
    for (const id of ids) { for (const h of hits) add(id, Math.round((t0 + h / 30) * fps));
      for (let f = Math.round(t0 * fps), e = Math.round((t0 + span) * fps); span && f <= e; f++) put(id, f, .3); }
  }
  for (const p of props || []) for (const k of p.keys || []) { if (k.snap) add(p.id, Math.round(k.t * fps));
    if (!k.optsOnly && ['in', 'owner', 'at'].some(f => f in k) && (k.pass ?? .1) > .02) for (let f = Math.floor((k.t - (k.pass ?? .1)) * fps), e = Math.ceil((k.t + (k.pass ?? .1)) * fps); f <= e; f++) put(p.id, f, 1); }
  return out;
}

//   lowCams(shots, characters, rests)  -> camera height floor: a shot's camera never sits below the subject's chest (legs read 1:1 with
//                                         the torso, as on the cast sheet). The SOP B8.7 low angle (camera below the eyes) is kept.
//   filmEnd(film, voice, characters, rests, handovers, authored) -> { dur, why }: the film ends `endHold` (default .5 s) after the last
//                                         word or action (pose motion, walks, clips, hand-overs), capped by the authored length.

const bodyAt = (c, rest, t) => { const P = evalPose(c.timeline, t, rest); const hip = P.body.hipY ?? rest.hipY;
  const y = P.root.y || 0; return { x: P.root.x || 0, z: P.root.z || 0, hip: hip + y, head: hip + y + hh(rest) }; };

// ---- item 5: low cameras. In a 9:16 frame nearly every shot shows the legs; a camera below the subject's chest (blind3: y 1.0-1.3 under
// heads at 2.3-2.7) drew the noodle legs ~1.6x the torso (the 2.5D torso is drawn with damped elevation, the 3D legs are not). Floor =
// the subject's chest (hip + .5 x hip-to-head), never above eyes - .45 (the low-angle feel stays). Subject = `who`, else the character
// nearest the camera target on the ground at the shot middle. `lowCam: true` on a shot/camera (or film `lowCams: false`) keeps it as authored.
export function lowCams(shots, characters, rests, { log = () => {} } = {}) {
  let n = 0;
  const out = shots.map((s, i) => {
    const c = s.camera || {}; if (c.lowCam === true || s.lowCam === true || c.move === 'orbit') return s;
    const a = num(s.t0) ? s.t0 : 0, b = num(s.t1) && s.t1 < 90 ? s.t1 : (num(shots[i + 1]?.t0) ? shots[i + 1].t0 : a + 2), tm = (a + b) / 2;
    const tgt = c.target || c.to?.target || c.from?.target;
    let subj = null;
    const cand = characters.filter(ch => rests[ch.name]).map(ch => ({ ch, B: bodyAt(ch, rests[ch.name], tm) }));
    if (c.who) subj = cand.find(x => x.ch.name === c.who);
    if (!subj && Array.isArray(c.whos)) subj = cand.filter(x => c.whos.includes(x.ch.name)).sort((p, q) => p.B.head - q.B.head)[0];
    if (!subj && Array.isArray(tgt)) subj = cand.sort((p, q) => Math.hypot(p.B.x - tgt[0], p.B.z - tgt[2]) - Math.hypot(q.B.x - tgt[0], q.B.z - tgt[2]))[0];
    if (!subj) return s;
    // everyone standing within 3 D of the subject is in the shot too: the tallest chest sets the floor (a seated subject + a standing one)
    const near = Array.isArray(tgt) ? cand.filter(x => Math.hypot(x.B.x - subj.B.x, x.B.z - subj.B.z) < 3) : [subj];
    const floor = Math.min(Math.max(...near.map(x => x.B.hip + .5 * (x.B.head - x.B.hip))), subj.B.head - .3);   // never above the subject's eyes (B8.7)
    const fix = p => Array.isArray(p) && p[1] < floor - .01 ? [p[0], +floor.toFixed(3), p[2]] : p;
    let cam = c, changed = false;
    if ((c.move || 'park') === 'park' && Array.isArray(c.pos)) { const p = fix(c.pos); if (p !== c.pos) { cam = { ...c, pos: p }; changed = true; } }
    else if (c.move === 'push' && c.from?.pos && c.to?.pos) { const p0 = fix(c.from.pos), p1 = fix(c.to.pos);
      if (p0 !== c.from.pos || p1 !== c.to.pos) { cam = { ...c, from: { ...c.from, pos: p0 }, to: { ...c.to, pos: p1 } }; changed = true; } }
    else if (c.move === 'follow') { const off = c.camOffset || [0, 2, 9]; if (off[1] < floor - .01) { cam = { ...c, camOffset: [off[0], +floor.toFixed(3), off[2]] }; changed = true; } }
    if (!changed) return s;
    n++; log(`camera floor: S${i + 1} camera raised to y ${floor.toFixed(2)} (${subj.ch.name}'s chest; was ${(c.pos || c.from?.pos || c.camOffset || [])[1]})`);
    return { ...s, camera: { ...cam, _floor: +floor.toFixed(3) } };
  });
  return { shots: out, n };
}

// ---- item 4: where the film ends. Pose motion (root, body, limbs, props; NOT the face) sampled every frame: the last moving frame is the
// last action. Words: voice words / lines. Hand-overs: t + hold + back.
const sig = P => { const o = []; const walk = (x, k) => { if (k === 'face' || k === 'listenGaze' || k === 'look') return;
  if (typeof x === 'number') o.push(x); else if (Array.isArray(x)) x.forEach(v => walk(v)); else if (x && typeof x === 'object') for (const [kk, v] of Object.entries(x)) walk(v, kk); };
  walk(P); return o; };
export function lastAction(characters, rests, t1, fps = 30) {
  let last = 0, who = null;
  for (const ch of characters) { const r = rests[ch.name]; if (!r) continue;
    let prev = null;
    for (let f = 0; f <= Math.round(t1 * fps); f++) {
      const s = sig(evalPose(ch.timeline, f / fps, r));
      if (prev && s.length === prev.length) { let m = 0; for (let i = 0; i < s.length; i++) m = Math.max(m, Math.abs(s[i] - prev[i]));
        if (m > .004 && (f - 1) / fps >= last) { last = f / fps; who = ch.name; } }
      prev = s;
    }
  }
  return { t: last, who };
}

export function filmEnd(film, voice, characters, rests, handovers, fps = 30) {
  const authored = film.duration ?? ((voice.lines.length ? Math.max(...voice.lines.map(l => l.end)) : 0) + (film.tail ?? 1.6));
  const lastWord = Math.max(0, ...voice.words.map(w => w.end), ...voice.lines.map(l => l.end));
  const ho = Math.max(0, ...(handovers || []).filter(h => num(h.t)).map(h => h.t + (h.hold ?? .2) + (h.back ?? .35)));
  const act = lastAction(characters, rests, authored, fps);
  const lastAct = Math.max(lastWord, act.t, ho);
  const hold = film.endHold ?? .5;
  let dur = num(film.endHold) ? lastAct + hold : Math.min(authored, lastAct + hold);
  if (film.endHold === false) dur = authored;
  dur = Math.max(dur, lastWord + .3, 1);
  const why = `last word ${lastWord.toFixed(2)} s, last action ${act.t.toFixed(2)} s${act.who ? ` (${act.who})` : ''}${ho ? `, last hand-over ${ho.toFixed(2)} s` : ''}`;
  return { dur: +dur.toFixed(4), authored, lastWord, lastAct, why };
}

// ---- item 4: mouths closed at the end. The face's mouth from the last face key (the voice's talk ends on its own): an open one
// (OPEN below, or anything not in CLOSED) still showing .4 s before the end gets a `rest` key after the last word.
const CLOSED = new Set(['rest', 'flat', 'frown', 'smile', 'smirk', 'grin', 'pout', 'line', 'closed', 'sad', 'tight', 'wry', 'neutral', 'content', 'press']);
export function closeMouths(characters, voice, dur) {
  const done = [];
  for (const ch of characters) {
    const keys = (ch.timeline.face || []).filter(k => num(k.t) && k.mouth != null && k.t < dur).sort((a, b) => a.t - b.t);
    const k = keys[keys.length - 1]; if (!k || CLOSED.has(String(k.mouth))) continue;
    const mine = voice.words.filter(w => w.who === ch.name), lw = Math.max(0, ...voice.words.map(w => w.end));
    const t = Math.min(dur - .3, Math.max(lw + .15, k.t + .5, mine.length ? mine[mine.length - 1].end + .15 : 0));
    if (t <= k.t) continue;
    ch.timeline.face = [...(ch.timeline.face || []), { t: +t.toFixed(4), mouth: 'rest', react: false, _fix1: 'end' }];
    done.push(`${ch.name} "${k.mouth}" closed at ${t.toFixed(2)} s`);
  }
  return done;
}

// ---- item 4: the end frame must be framed. A head counts as framed when it is inside the frame with >= 150 px (short side 1080) diameter.
// When the last frame has none, the latest earlier shot whose own last frame (inside the film) is framed runs on to the end.
export async function endFraming(scene, dur, fps, openStage, { minPx = 150, minLast = 1.0, log = () => {} } = {}) {
  const shots = scene.shots || []; if (shots.length < 2) return null;
  const wide = scene.width > scene.height, fw = wide ? 192 : 108, fh = wide ? 108 : 192;   // (the film's own frame shape: a tenth of 1080x1920 or 1920x1080)
  const st = await openStage({ ...scene, width: fw, height: fh }, {});
  const framed = async t => { const r = await st.frame(t); const s = (wide ? 1920 : 1080) / 108;   // (one camera, one verdict: a head is the same share of the frame height)
    return r.views.some(v => v.d * s >= minPx && v.cx > 0 && v.cx < fw && v.cy > 0 && v.cy < fh); };
  const tEnd = Math.max(0, dur - 1 / fps);
  let res = null;
  const idx = shots.reduce((k, s, i) => (tEnd >= (s.t0 ?? 0) ? i : k), 0);
  try {
    // a cut in the last `minLast` s (the film was shortened to the last action: coffee_break cut to a new wide 0.5 s before the end)
    // is a flash, not a shot: the shot before runs on to the end when its own last frame is framed
    const short = idx > 0 && dur - (shots[idx].t0 ?? 0) < minLast;
    if (short) { const a = shots[idx - 1].t0 ?? 0, b = Math.min(shots[idx].t0, dur);
      if (await framed(Math.max(a, b - 1 / fps))) res = { keep: idx - 1, from: idx, why: `the last shot S${idx + 1} would last only ${(dur - shots[idx].t0).toFixed(2)} s` }; }
    if (!res && await framed(tEnd)) return null;
    if (!res) for (let i = idx - 1; i >= 0; i--) {
      const a = shots[i].t0 ?? 0, b = Math.min(shots[i + 1].t0, dur);
      if (await framed(Math.max(a, b - 1 / fps))) { res = { keep: i, from: idx, why: `the last frame shows no head of ${minPx}+ px (shot S${idx + 1})` }; break; }
    }
  } finally { await st.close(); }
  if (!res) return null;
  log(`END: ${res.why}: shot S${res.keep + 1} runs to the end`);
  return res;
}

"""Pixel measurements for one probed still (fudai-wall pixel gate).

Usage: pixel_measure.py <still.png>
Prints one JSON object:
  flat_pct / detail_pct  - RULES S5 block measure: 32x32 blocks on grayscale;
                           flat block = std < 5, detail block = std >= 12.
  discs                  - rendered head discs found by skin segmentation:
                           a skin component ringed by the characters' dark
                           outline. Each disc: skin bbox, expanded bbox
                           (outline + hair/hat allowance, +12% per side),
                           area, dark-adjacency ratio.
Calibration (2026-11-23, chunk2d stills): F537 mocker silhouette 648x624 px
vs the staging audit's 480 px model disc (1.32x, hat-inclusive); F687 mayor
disc centre (553,30) r~473 vs projected (540,653) r448 - the gate therefore
MEASURES discs in the image instead of trusting projected centres.
"""
import json, sys
import numpy as np
from PIL import Image
from scipy import ndimage

def components(mask):
    lab, n = ndimage.label(mask)
    return lab, n

def main():
    path = sys.argv[1]
    img = Image.open(path).convert('RGB')
    a = np.asarray(img).astype(np.int32)
    H, W = a.shape[:2]
    R, G, B = a[:, :, 0], a[:, :, 1], a[:, :, 2]

    # ---- S5 block measure (grayscale, 32x32 blocks) ----
    gray = (0.299 * R + 0.587 * G + 0.114 * B)
    bs = 32
    nb = 0; flat = 0; detail = 0
    for y in range(0, H - bs + 1, bs):
        for x in range(0, W - bs + 1, bs):
            s = gray[y:y + bs, x:x + bs].std()
            nb += 1
            if s < 5: flat += 1
            if s >= 12: detail += 1
    flat_pct = round(100.0 * flat / nb, 1)
    detail_pct = round(100.0 * detail / nb, 1)

    # ---- head discs: skin mask + dark-outline adjacency ----
    skin = (R > 130) & (R - B > 25) & (R - G > 8) & (R - G < 95) & (G - B > 5) & (G - B < 80)
    dark = (R < 85) & (G < 75) & (B < 75)
    lab, n = components(skin)
    discs = []
    if n:
        for root in range(1, n + 1):
            m = lab == root
            area = int(m.sum())
            if area < 6000:
                continue
            ys, xs = np.nonzero(m)
            x0, x1, y0, y1 = int(xs.min()), int(xs.max()), int(ys.min()), int(ys.max())
            # dark adjacency: dilate by 3 px, ring = dilated & ~m
            d = ndimage.binary_dilation(m, iterations=3)
            ring = d & ~m
            ring_n = int(ring.sum())
            adj = float((ring & dark).sum()) / ring_n if ring_n else 0.0
            bw, bh = x1 - x0 + 1, y1 - y0 + 1
            aspect = bw / max(bh, 1)
            if adj < 0.30 or not (0.55 <= aspect <= 2.3):
                continue
            ex = round(bw * 0.12); ey = round(bh * 0.12)
            discs.append({
                'skin': [x0, y0, x1, y1],
                'disc': [max(0, x0 - ex), max(0, y0 - ey), min(W - 1, x1 + ex), min(H - 1, y1 + ey)],
                'centre': [round((x0 + x1) / 2), round((y0 + y1) / 2)],
                'area': area, 'adj': round(adj, 2),
            })
    discs.sort(key=lambda d: -d['area'])
    print(json.dumps({'file': path, 'size': [W, H], 'flat_pct': flat_pct,
                      'detail_pct': detail_pct, 'discs': discs}))
