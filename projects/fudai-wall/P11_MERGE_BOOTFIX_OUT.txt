  for (let i = 0; i < 3; i++) {
    const d = p1[i] - p0[i];

**Root cause:** [`scenes/props/birds.js`](/home/hatch/workspace/fudai-rebuild/studio/projects/fudai-wall/scenes/props/birds.js) passed an empty `BufferGeometry` to `part()`. `part()` calls `outline()` immediately, and `engine/shade.js:hullNormals()` reads `geo.attributes.position.count`. The position attribute was added only afterward, so boot failed with `Cannot read properties of undefined (reading 'count')`.

**Fix diff:**

```diff
- const w=part(new THREE.BufferGeometry(),m,.003);
- const v=new Float32Array([x,0,0,x+s*.16,.04,0,x+s*.13,.01,.015]);
- w.geometry.setAttribute('position',new THREE.BufferAttribute(v,3));
- w.geometry.computeVertexNormals();
+ const geometry=new THREE.BufferGeometry();
+ const v=new Float32Array([x,0,0,x+s*.16,.04,0,x+s*.13,.01,.015]);
+ geometry.setAttribute('position',new THREE.BufferAttribute(v,3));
+ geometry.computeVertexNormals();
+ const w=part(geometry,m,.003);
```

The geometry now has positions and normals before `part()` creates its outline.
