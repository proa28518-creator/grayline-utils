# Example: the S-4 short (sunken submarine, 39 s), pass by pass

## The brief
- 1927: a Coast Guard cutter rams the submarine S-4; six men trapped in the torpedo room tap "Is there any hope?" on the hull; the storm stops the divers; by dawn the knocking has stopped.
- One narrator, nobody speaks on screen: faces, hands and knocks act the words. 14 characters in five places (torpedo room, sea, rum runner's boat, storm deck, seabed).
- Made from a voice file to a finished film in 2 h 42 min, one fresh Claude per pass. gruss: "the quality of this video is so good if you don't tell me it had problems i wouldn't even notice the gaps you mentioned."

## Where the full files are
- Film, camera, post, shading and props: `.claude/skills/cartoon-shorts/examples/s4_shade/` (`film.mjs`, `shots.mjs`, `post.mjs`, `shade.mjs`, `props/` = hammer, knockfx, airhose, oscillator, `cameras/s4.json`).
- The set: `examples/s4_shade/set/s4.js` (pass 1 previz) and `examples/s4_shade/set/s4_env.js` (pass 3 onward).

**This is a lesson, not a kit.** A member's film is written new from its own words, with its own cast, acting, shots, camera and set,
even when its voice is the same as this one: take the method and the bar from here, never the film, its acting table, its shots or its set.

**What the example did that a member film does differently.** It lived in our work folder, not in a project:
- The set was a named shared set (`world/s4.js`, `world/s4_env.js`, registered in `world/sets.js`, `world: { set: 's4_env' }`); those
  modules are not in a member's project. A member film builds its OWN set for its own story in `scenes/set.js` (`export async function buildSet(THREE, scene, opts, kit)`) with `world: { set: 'own', setOpts: {...} }`, imports the engine's look modules by relative path (`'../world/look/lights.js'`), and loads its own files from `new URL('../assets/set/', import.meta.url)` and `'../assets/tex/'`.
- The film was `film.mjs` with `shots.mjs` / `post.mjs` / `shade.mjs`; in a project these are `scenes/film.js`, `./shots.js`, `./post.js`, `./shade.js`. Specs were shared ids (`s4_kid`); a member's own cast is `spec: 'cast/s4_kid.json'`.
- The voice was trimmed by our tool into `voice/vo_trimmed.wav`; in a project it is `audio/clean.wav` + `audio/clean.json`, already made by the app.
- Knock sounds were made in code and mixed by our tools, and the final grade ran in ffmpeg. In the app the sound design is automatic and the in-page post grades the frames: no sound steps.
- Pass 1 added the `knock` clip and the `diver` hat to the shared engine; they are in the engine copy now. A member film that needs a new clip or hat does it with what the engine has (a prop, a spec) or reports the gap.

## Pass 1: Build (characters, acting, basic scenes), 38 min
**What it did:** 11 specs, the six men in a cramped steel room, the skipper, the smuggler, the Navy man, divers; a lit previz set with all five places; knocks on the words; one hammer per man; an impact ring on every knock so the audience SEES each one.
**What made it work:** `film.js` instead of JSON. One table of knocks drove the hands, the rings and (in our run) the sound, so they could never drift apart. Faces carry the beats (reaction faces 1-3 frames after the trigger), bodies jolt on the ram.

The knock table drives the hands (`scenes/film.js`):
```js
const SPOT = {  // root, facing, hem height, hand side, hand at impact (world), tool head at impact (where the ring shows)
  kid: { at: [-1.1, .95], ry: -20, hy: .55, side: 'R', hand: [-1.56, 1.62, .95], head: [-1.88, 1.82, 1.06], rotHit: [0, 0, 62], rotUp: [0, 0, 24], ring: .55 },
  lt:  { at: [-3.25, .5], ry: 30, hy: 1.42, side: 'L', hand: [-2.58, 2.3, .85], head: [-2.22, 2.5, .98], rotHit: [0, 0, -62], rotUp: [0, 0, -24], ring: .5 },
};
const run = (who, times, o = {}) => times.map((t, i) => ({ who, t, ...(typeof o === 'function' ? o(i) : o) }));
export const KNOCKS = [
  ...run('kid', [.72], { rise: 6, back: 3, label: 'first tap' }),
  ...run('kid', [16.46, 16.92, 17.38, 17.84, 18.3, 18.76], i => ({ rise: 8, back: 5, label: 'slow knock back ' + (i + 1), out: i === 5 ? { hold: .3, out: 8 } : null })),
];
const knockClips = who => { const s = SPOT[who], out = [];
  for (const k of KNOCKS.filter(x => x.who === who)) {
    const rise = k.rise ?? 3;
    const e = { clip: 'knock', t0: +(k.t - rise / 30).toFixed(3), params: { side: s.side, to: toBody(s.at, s.ry, s.hy, s.hand), rise, back: k.back ?? 3, prop: 'tool_' + who, rotUp: s.rotUp, rotHit: s.rotHit } };
    if (k.out) { e.hold = k.out.hold; e.out = k.out.out; }
    out.push(e);
  }
  return out; };
```
The same table makes the rings (a prop `scenes/props/knockfx.js`, keyed by `a`):
```js
const ringsOf = who => { const s = SPOT[who], keys = [];
  for (const k of KNOCKS.filter(k => k.who === who)) keys.push({ t: k.t, a: 0 }, { t: +(k.t + .034).toFixed(3), a: 1, ease: k.soft ? .22 : .3 });
  return { id: 'r_' + who, kind: 'knockfx', in: 'world', at: s.head, size: s.ring, a: 1, keys }; };
```

```js
  /* cast, props, acts, shots: SHOTS, captions: 'words' */ };
```
The set: places 400 D apart, each in its own dome (writing depth) and fog, everything animated pure in t (`scenes/set.js`, from `set/s4.js`):
```js
export const ZONES = { SEA: [400, 0], BOAT: [400, -400], STORM: [400, 400], BED: [-400, 0] };   // the torpedo room is at (0, 0)
export async function buildSet(THREE, scene, opts, kit) {
  const group = new THREE.Group(); scene.add(group); const A = opts.anim || {};
  const dome = (x, z, top, low, r = 170) => { /* gradient sphere, BackSide, depthWrite: true, renderOrder -10 */ };
  dome(0, 0, '#050608', '#07080b', 90);           // one per place
  function update(t) { /* lamp dims along A.lamp, the cutter charges to A.ram, S-4 sinks over A.sink, storm until A.calm */ }
  update(0);
  return { group, marks: { pipe: [-2.05, .95] }, points: { lamp: [0.9, 4.15, 1.4] }, update };
}
```

## Pass 2: Camera, "Through the Steel", 22 min
**What it did:** 23 `path` shots. The idea, from the subagent: the camera goes where the sound goes. The knock crosses the steel, so the camera does; the question climbs 30 m of water, the answer drops back through the deck onto their faces. Hard cuts only where a hit is stronger than a glide (the jolt, "She drops", the storm, the question, the dawn).
**What made it work:** hidden seams between places (two paths meeting on the same kind of frame), crossings under 8 frames, close faces at fov 26 with a slow push between them. gruss: "Camera work on this last video was borderline insane ... clean asf. This style is going to be HUGE." The instruction set is `cameras/s4.json`.

The helpers and the seam table (`scenes/shots.js`):
```js
const k = (t, pos, target, fov = 26, roll = 0, shake = 0, x = {}) => ({ t, pos, target, fov, roll, shake, ...x });
const path = (t0, t1, keys) => ({ t0, t1, camera: { move: 'path', keys } });
export const SEAMS = { surface: [[2.9, 3.62], [30.8, 30.94]] /* + where each place is on screen */ };
```
A seam pair, the swish: the same sky and sea in two places, turning the same way on both sides of the cut:
```js
path(3.62, 6.12, [ /* ... rise up the cutter's side, fly out ahead of her */
  k(6.02, S(88, 10, 13), S(0, 3, 0), 30, 3),
  k(6.12, S(88, 10, 13), S(88 - 17, 10, 13 + 98), 32, 3) ]),          // swing away over the sea
path(6.12, 7.04, [                                                     // another place, still swinging
  k(6.12, B(-.3, 1.85, 13.8), B(-.3 + 17, 2, 13.8 + 98), 32, 3),
  k(6.25, B(-.3, 1.85, 13.8), B(-1.1, 2.3, 1.2), 26, 3, 0, { stop: true }),   // lands on the smuggler
  k(7.04, B(-.5, 1.85, 12.8), B(99, 2.3, 12.8), 28, 2) ]),
```
Riding the sinking sub: keys every 0.1 s from the set's own fall formula (a `path` key `pos: { object: 'sub', offset: [22, 6, -9] }` does this in one line now):
```js
const subY = t => { const g = Math.max(0, Math.min(1, (t - 10.04) / 1.4)); return 44 - 39.4 * g * g; };
const fallKeys = []; for (let t = 10.02; t < 11.44; t += .1) { const y = subY(t), u = (t - 10.02) / 1.42;
  fallKeys.push(k(+t.toFixed(2), U(22, y + 6, -9), U(-6, y + 3.6, -9), 46, 3 - 6 * u, .4 + u)); }
```

## Pass 3: Environment crew, 39 min (Blender 29, textures 33, integration 38, at once)
**What it did:** Blender modelled a cramped riveted torpedo room (tube doors with breech wheels, racks, bunks, pipes, gauges), the wreck and seabed, the ships and the boat, with geometry-node scatter for rust, growth and debris. Flow made flat plate, deck, sand and paint textures, a 6 x 6 decal sheet, skies and inked sprite sheets. Three.js lit it live with lights as data.
**What made it work, biggest first:** the real room; light in linear with soft falloff so pools form and the characters jump out; lights as data (a one-line change and a 10 s re-render); a cage gobo on the lamp whose bars crawl over the tube doors as it swings from the jolt; water and sky in the shader.
**Contract first:** one writer per file; `assets/set/<place>.glb` place-local, one glb per moving thing (`sub.glb`, the ships) placed inside its animated group; `scatter.json`; decal cell ranges and material names fixed before anyone starts (they weren't, and cost time).

## Pass 4: Post processing, 31 min
**What it did:** per place: depth of field, haze by height and distance with the place's lights hanging in it, bloom, particles as data (dust in the lamp light, rust shaken off the overhead on the jolt and the landing, silt and bubbles underwater, sleet and spray in the storm, gold motes at dawn), and the grade inside the pipeline.
**What made it work:** depth of field and haze on the torpedo room (the steel stopped competing with the faces, at the bar on the first render with the backrooms' values); a different light model for water (fade from the real surface, wide shafts); haze density keyed per shot so the sinking sub stays readable.

## Pass 5: Shading, 29 min
**What it did:** shaded characters and props from the set's own lights (`rig.sample(place, t)`): key and shadow as two colours, a floor per place, the helmets as metal spheres, and moods per beat.
**What made it work:** amber on the lamp's side, cold on the far side, with the cold constant, so the room grows colder by itself as the lamp dies. Moods: the hook hard, the six knocks warm, "air is very bad" sick and hard, the question lights one man, "There is hope" warm, the last shot loses light over 2.4 s.

`scenes/shade.js`:
